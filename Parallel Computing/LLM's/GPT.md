#LLM #Transformer #Decoder-only

Decoder Only transformer variant.
Generated Pre-trained Transformer: 

![[Pasted image 20261108191950.png]]
Keep the decoder part only to formulate a text to text 
problem. Take text as input and predict the next token. Auto regressive decoding.

No need for fine tuning but can be done to improve model.
Can be used for semantic extraction with the example of is this sentence positive or negative and the output would be just yes or no.

Treat the input same as output and is the go to model vs encoder-decoder architecture since it was simpler and performed better.
