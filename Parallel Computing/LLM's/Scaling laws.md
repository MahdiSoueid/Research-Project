#LLM 

A paper found out that better performance is with bigger models and bigger data.

The bigger the model -> the more token efficient it is.

This is subject to compute power:
FLOPs ( Floating-point operations): meant to measure the compute -> the higher the FLOPs the more the compute.

FLOPS (Floating-point operations per second): Compute speed measuring the hardware power.

There is a sweet spot between model size and training data size and it found that most models where undertrained compared to their size.
